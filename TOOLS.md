
1. Static Application Security Testing (SAST)

• Purpose: Scans your proprietary source code, bytecode, or binaries for security bugs and vulnerabilities before the code runs ("inside-out" testing).
• Popular Tools:
	• SonarQube: A hybrid tool bridging code quality and security bugs.
	• Checkmarx SAST: Deep enterprise-grade scanning with massive language coverage.
	• Semgrep: A lightweight, lightning-fast scanner that allows developers to write custom rules quickly.
	• GitHub CodeQL: The industry standard for semantic code analysis built directly into GitHub.

2. Software Composition Analysis (SCA)

• Purpose: Scans the application supply chain, mapping out open-source third-party frameworks, dependencies, and libraries for known vulnerabilities (CVEs).
• Popular Tools:
	• Snyk: Extremely developer-friendly tool providing inline remediation suggestions.
	• OWASP Dependency-Check: A highly capable open-source baseline scanner.
	• Syft & Grype: Open-source tools by Anchore that work in tandem—Syft generates a Software Bill of Materials (SBOM) and Grype scans it.

3. Secrets Scanning

• Purpose: Prevents developers from accidentally pushing unencrypted API tokens, cryptographic keys, and database passwords into source control repositories.
• Popular Tools:
	• TruffleHog: Searches deep through commit histories for active secrets.
	• GitLeaks: A highly structured tool for discovering secrets in CI pipelines.
	• GitHub Secret Scanning: Automatically blocks commits if known credential formats are leaked.

4. Dynamic Application Security Testing (DAST)

• Purpose: Evaluates running applications in a staging or production-like environment by launching simulated cyberattacks ("outside-in" testing) to find runtime/config vulnerabilities.
• Popular Tools:
	• OWASP ZAP: The industry baseline for automated web application and API security tests.
	• Burp Suite Enterprise: Great for combining automated CI scans with manual pen-testing hooks.
	• HCL AppScan: An enterprise platform designed for testing live endpoints and web apps.

5. Infrastructure as Code (IaC) Scanning

• Purpose: Scans configuration files (e.g., Terraform, CloudFormation, Kubernetes manifests) for infrastructure misconfigurations before the resources are spun up in the cloud.
• Popular Tools:
	• Checkov: A graph-based scanner that looks for misconfigurations across Terraform, Helm charts, and Dockerfiles.
	• Terrascan: Policy-as-code tool utilizing 500+ built-in rules mapped to CIS benchmarks.
	• Open Policy Agent (OPA): A powerful tool enabling generalized policy enforcement across the entire cloud-native infrastructure.

6. Container and Runtime Security

• Purpose: Audits base OS layers inside Docker/OCI container images during the build phase and monitors active anomalies or threats during application execution.
• Popular Tools:
	• Trivy: An all-in-one multi-target scanner built by Aqua Security for packages, containers, and IaC files.
	• Clair: An open-source parsing tool utilized for static vulnerability analysis of app containers.
	• Falco: A runtime security tool that monitors system logs and behavior in Kubernetes environments to block anomalous activity in real time.

7. ASPM (Application Security Posture Management)

• Purpose: Consolidates, deduplicates, and manages the thousands of alerts generated by all the scanners listed above.
• Popular Tools:
	• DefectDojo: An open-source aggregator that connects with 500+ security tools to organize the vulnerability lifecycle.



Tool Category	When it Runs in the CI/CD Pipeline	Ideal For
Secrets Scanning	Pre-commit / Code Commit	Finding leaked API keys and credentials
SAST	Pull Request / Code Build	Finding developer syntax bugs and insecure logic
SCA	Code Build Stage	Catching buggy or out-of-date open-source libraries
IaC Scanning	Infrastructure Pre-deployment	Flagging exposed cloud resources or open firewalls
Container Scan	Registry Push Stage	Auditing Linux package flaws inside Docker layers
DAST	Post-deployment Testing	Simulating real attacks against active URLs/endpoints
Runtime Security	Continuous Production Monitoring	Catching unexpected zero-days or system file changes
